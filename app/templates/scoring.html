Good to know

  • File and folder names are matched case-insensitively. Apart from CI workflows, which are read from .github/workflows, only the repository’s root directory is checked.
  • Counts read from GitHub list endpoints stop at {{ api_page_cap }} (one page of results), which is enough for every threshold above.
  • A check rewards the presence of a file, not its quality: an empty SECURITY.md earns the same points as a thorough one. Treat the score as a checklist, not a verdict.
  • Each report shows these checks with what was found, under “Dimension scores”. A test runs the real scorer against this page’s numbers.
